# 実装計画: SwitchBot Data Pipeline

## 概要

SwitchBot APIからデータを取得し、AWS Glueを使用してデータパイプラインを構築するシステムをTypeScriptとAWS CDKで実装します。プロジェクト構造は以下の通りです：

- `packages/cdk/` - AWS CDKインフラストラクチャコード
- `packages/api/` - Lambda関数のTypeScriptコード
- `packages/cdk/glue-scripts/` - Glue ETL Job用Pythonスクリプト

段階的にコンポーネントを構築し、各段階でテストを実行して動作を確認します。

## 注意事項

- `*`マークのタスクはオプションで、より迅速なMVPのためにスキップ可能

- プロパティテストは汎用的な正確性プロパティを検証
- ユニットテストは特定の例とエラー条件を検証
